# Прототип: инструкция доски — системный промпт или обогащение

Отвечает на вопрос тикета
[#13](https://github.com/MaksimKhanin/FamilyAssistant/issues/13):
куда класть инструкцию доски при работе ассистента и стабильно ли модель семьи
считает статистику по сырым записям.

- `fixture.txt` — реальный лог питания/сна (из постановки тикета).
- `gold.md` — эталонные ответы, посчитанные руками, и каталог ловушек фикстуры.
- `run.py` — прогоняет 3 вопроса × 2 сборки промпта (`system` / `enrichment`)
  × 2 редакции инструкции (`base` / `extended`) × N повторов через модель
  из вашего `.env` (тот же `LLM_BASE_URL`/`LLM_MODEL`, что у панели).

Запуск из корня репозитория:

```bash
python -m prototype.board_instruction.run
```

На что смотреть в выводе (по `gold.md`):

1. **Ловушка «Итого»**: сумма за сутки 900, а не 1800 — и лечит ли её `extended`.
2. **Сутки по времени события**, а не отправки (кормление «4-10» — это 04:10).
3. **Оговорки**: «в среднем за неделю» при двух полных днях данных; сон — только
   зафиксированные интервалы.
4. **Разброс между повторами** одной клетки — это и есть (не)стабильность.
5. **system против enrichment**: есть ли разница в точности вообще.
