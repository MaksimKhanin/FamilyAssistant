# Записи на чужих досках переживают своего автора

Правило ядра — «удаление человека уносит его данные каскадом по внешним ключам»
(`docs/architecture.md`). Для записей на досках сделано одно осознанное
исключение: при удалении участника его записи на **чужих** досках остаются,
`author_id` обнуляется, и лента показывает «бывший участник». Каскадом гибнет
только то, чем человек владел: его разделы, его доски и всё их содержимое.

Причина: запись на чужой доске принадлежит документу, а не автору. Доска — это
совместный лог (кормления, сон ребёнка), и дыры на месте чужих записей ломают
и его читаемость, и статистику, которую ассистент по нему считает. Половина
лога кормлений, исчезнувшая вместе с удалённой учёткой, — потеря данных для
всех оставшихся, а не уборка за ушедшим.

Цена: текст записей удалённого человека остаётся в базе семьи. Это признано
приемлемым, потому что писал он их в чужой документ добровольно — как сообщение,
отправленное в общий чат, которое тоже не исчезает у получателей.

Это записано, чтобы следующий человек не «дочинил» каскад до полного: обнуляемый
`author_id` здесь — решение, а не забытый `ondelete`.
