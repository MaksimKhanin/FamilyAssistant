# Дизайн-система

Реализация дизайн-пакета «Семейный ассистент — веб-панель». Токены живут в
`app/static/style.css`, разметка — Jinja-шаблоны в `app/templates/`.

## Тон — это требование, а не оформление

Ассистент — заботливый член семьи, не система мониторинга. Практически это значит:

* **«оценка», а не «расчёт»**. Черновик приёма пищи всегда с бейджем `≈ оценка`,
  рядом — прямая оговорка, что это не медицинский расчёт;
* **никаких «плохих» продуктов**, никаких предупреждений о весе, никакого осуждения.
  Даже когда норма превышена — «ничего страшного, если хотите, соберу идеи полегче»;
* **дом без драматизма**. Тревога однозначна по смыслу («⚠️ кто-то у калитки в 23:14»),
  но без красных мигающих экранов, и всегда с оговоркой «это оценка модели, а не факт»;
* **план — это идеи**. На экране плана первая же строка: «Это идеи, а не предписание».

Копирайт переносится дословно из дизайн-пакета. Если правите текст — сверяйтесь с
этими правилами, а не с тем, как «принято в дашбордах».

## Токены

Акцент — одна переменная `--acc` (по умолчанию `#2E6E7E`), всё остальное считается от
неё через `color-mix`. Семья может поменять акцент (`FamilySettings.accent_color`), и
интерфейс поедет целиком, без правки тридцати литералов.

| Роль | Значение |
|---|---|
| Фон / поверхность / вторичная подложка | `#F1EADF` / `#FFFCF6` / `#F7F2E9` |
| Текст: основной / вторичный / приглушённый / подписи | `#23201C` / `#6E665C` / `#8A8177` / `#A79C8E` |
| Тёмная панель (дом, лог агента) | `#2E3A33`, текст `#EDE7DB` |
| Успех, «сам сделал», тумблер вкл | `#5F7A5A` |
| Тревога | `#B3452F`, подложка 11% |
| Внимание, «оценка» | `#D99A2B`, подложка 16% |

Шрифты: **Playfair Display** 500/600 — заголовки и крупные числа; **Manrope** — всё
остальное; моноширинный — **только** имена инструментов (`log_meal`), чтобы техническое
в интерфейсе было визуально отделено от человеческого.

Радиусы 6–22px по возрастанию размера элемента, отступы кратны 4, теней почти нет —
только модалка, панель чата и тост.

## Каркас

```
sidebar 246px  |  header (sticky)
   логотип     |    заголовок · роль · «Спросить ассистента» · аватары семьи
   навигация   |─────────────────────────────────────────────
   «на связи»  |    содержимое экрана
                    + панель чата справа (430px, overlay)
                    + модалка тревоги · тост
```

Навигация собирается из `NavItem`, которые отдают модули (`app/web/context.py`).
Выключенный модуль не отдаёт ничего — его пункты исчезают. Пункты с `head_only`
скрыты у участника.

## Русский язык в интерфейсе

Плюрализация и падежи — фильтры Jinja (`app/core/templating.py`):

```jinja
{{ counters.total|counted("заметка", "заметки", "заметок") }}   → «5 заметок в памяти»
Для {{ user.display_name|genitive }} безопасность пока не включена
{{ event.happened_at|ru_datetime }}                            → «Сегодня, 23:14»
```

`genitive` намеренно простой: имена вводит сама семья, и «для Лёвы» важнее
академической точности на редких именах.

## HTMX

Используется ровно там, где перезагрузка страницы всё портит — в чате: отправка
сообщения дописывает пузыри в ленту и прокручивает её вниз. Всё остальное — обычные
формы с редиректом: для семейной панели на пять человек это надёжнее и понятнее.

htmx лежит в `app/static/htmx.min.js` (MIT), а не тянется с CDN: домашний сервер
должен работать и без интернета.
